# 19 Prompt Library — Skyline Rush

**Not applicable.** Skyline Rush has no generative AI, LLM, or chatbot
feature — see [[07_AI_OR_AUTOMATION_PIPELINE]] for the explicit scope
decision and the (non-generative) procedural content and dynamic-difficulty
automation that exists instead. This document is marked `not_applicable` in
`package_manifest.json` rather than left as an unfilled template.

If a future revision introduces any LLM-backed feature (for example, an
internal content-authoring assistant for the design team), it requires: a
PRD revision to [[01_PRD]], a safety/privacy review update to
[[08_SAFETY_PRIVACY_COMPLIANCE]], and this document populated with
versioned prompts, structured output schemas, and eval criteria before
shipping — per the package specification's requirements for any AI surface.
